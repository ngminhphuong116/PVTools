# PVTools

Ứng dụng Windows tập hợp các công cụ chuyển đổi file, xử lý PDF và tách nền ảnh trong cùng một giao diện.

## Giới thiệu

PVTools là dự án cá nhân mình phát triển để thực hành lập trình C# và xây dựng những công cụ phục vụ học tập, công việc hằng ngày.

## Chức năng chính

- **Chuyển đổi file:** hỗ trợ chuyển đổi định dạng tệp.
- **Công cụ PDF:** hỗ trợ xử lý và tách trang PDF.
- **Tách nền ảnh:** loại bỏ nền và chỉnh sửa ảnh.

## Công nghệ

- Ngôn ngữ: C#
- Nền tảng: Windows
